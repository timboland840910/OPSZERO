# Contributing to OPSZERO

Thank you for your interest in contributing to OPSZERO.

## How to Contribute

1. Fork the repository
2. Create a new branch for your changes
3. Commit your changes
4. Submit a pull request

## Guidelines

* Keep the architecture modular
* Follow the microservices design principles
* Write clear documentation
* Ensure code readability and maintainability

## Reporting Issues

If you find a bug or want to suggest an improvement, please open an issue in the repository.

## Vision

OPSZERO is an experimental platform exploring distributed systems, microservices, and event-driven architectures.
