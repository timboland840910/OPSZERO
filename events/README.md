# Events Directory

This directory contains definitions and schemas for events used within the OPSZERO application.

## Event Definitions
Event definitions specify the structure and content of the events that are emitted by the application. Each event type has its own definition to ensure clarity and consistency across the application.

## Event Schemas
Event schemas provide a structured format for validating the events that are created and processed. These schemas help ensure that the events adhere to the expected structure and include all necessary fields.

These definitions and schemas are critical for maintaining the integrity and functionality of the OPSZERO system, enabling robust event handling and processing.
